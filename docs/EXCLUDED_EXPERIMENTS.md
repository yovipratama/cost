# Out-of-scope historical material

This public release contains only code for experiments reported in the COST manuscript.

Not included: exploratory experiments not presented in the paper, old notebook-level experiments testing unrelated variants, historical journal-response and submission-specific audit cells, redundant notebook copies, and output-only or cached-patient artifacts.

The original Initial COST performance collapse and the sparsity sweep **are included** because they are material to the published paper, even though they were not the final optimized model.

Raw notebook filenames are retained only inside `docs/SOURCE_PROVENANCE.tsv` to document provenance, not as an experiment taxonomy or public notebook filename.
